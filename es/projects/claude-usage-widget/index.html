Claude Usage Widget

Aplicación para la bandeja de Windows que muestra el consumo de Claude Code: límites y cuentas regresivas en tiempo real, con un icono que cambia de color al acercarse al límite.

Ver en GitHubVer en GitHub

Desafíos

  • Ofrecer una forma sencilla de consultar el consumo de la suscripción de Claude Code desde un widget de escritorio.

Tecnologías utilizadas

  • Rust
  • React
  • TypeScript
  • Tailwind CSS
